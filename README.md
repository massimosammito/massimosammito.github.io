# massimosammito.github.io

Personal website / CV — plain HTML, CSS and a little JavaScript, no build step, served by GitHub Pages
at <https://massimosammito.github.io>.

## Files

| Path | What it is |
| --- | --- |
| `index.html` | The whole site — one page, all content |
| `style.css` | All styling, including light/dark themes and the phone layout |
| `script.js` | The moving parts: hero network animation, rotating line, scroll reveals, count-up numbers, timeline and publication filters, theme toggle. Honours reduced-motion. |
| `assets/Massimo_Sammito_CV.pdf` | Downloadable CV linked from the hero (exported from MyNextJob, Pharma / Biotech track) |

## Editing

Edit the files, commit, push. GitHub Pages redeploys in ~30 seconds.

To preview locally: `python3 -m http.server 8000` then open <http://localhost:8000>.
